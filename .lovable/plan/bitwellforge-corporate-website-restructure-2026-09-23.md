# BitwellForge corporate website restructure

## Direction

Create an original BitwellForge experience using the reference site's corporate publishing patterns as structural inspiration. The result will preserve BitwellForge's routes, mandated homepage copy, primary audit action, and existing product flows without copying the reference site's text, imagery, or proprietary brand expression.

## What will change

### Global navigation

Rebuild the public header as a precise horizontal desktop system with a transparent top state, crystal glass scrolled state, keyboard accessible mega menus, clear active states, and a full screen animated mobile menu. Keep every current destination, including Careers and Vault.

### Homepage

Replace the current homepage composition with four focused editorial bands:

1. Hero with the existing approved headline and description, a restrained parallax visual field, and the primary Book Infrastructure Audit action
2. Our Expertise with sharp editorial service panels and clear routes into the existing service pages
3. Latest Insights with a responsive three, two, and one column article grid using current BitwellForge insight content
4. Global Footprint with an abstract geographic field and accurate worldwide remote delivery positioning

### Footer

Rebuild the footer into structured desktop columns and accessible mobile accordions while preserving business and support email roles.

### Visual system and motion

Apply the supplied matte black, warm ivory, champagne gold, pure gold, titanium gray, and navy palette through semantic tokens. Use serif display typography, geometric sans body typography, sharp cards, restrained glass surfaces, image zoom and arrow motion, staggered fade up reveals, and reduced motion fallbacks.

## Technical details

Create small data driven homepage and navigation components rather than one monolithic page. Reuse existing routes and SEO hooks. Use GPU friendly transform and opacity animation only. Keep touch targets at least 44 pixels, use a 1440 pixel desktop measure, two column tablet grids, one column mobile grids, and prevent horizontal overflow at narrow widths.

## Verification

Check the homepage and navigation at phone, tablet, and desktop sizes in both themes. Verify mega menu keyboard behavior, mobile menu focus and dismissal, footer accordions, links, reduced motion, no overflow, no stuck overlays, exact approved metadata, and a clean production build.
